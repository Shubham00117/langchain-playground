What is a Tool?

A tool is just a Python function (or API) that is packaged in a way the LLM can understand and call when needed.

✓ LLMs are great at

  • Reasoning (Think)
  • Language generation (Speak)

✗ LLMs can't do

  • Access live data (weather, news)
  • Do reliable math
  • Call APIs
  • Run code
  • Interact with a database

Tools solve these limitations by wrapping real functions and giving the LLM structured access to them.

Tools are split into two categories: Built-in Tools and Custom Tools.

Custom Tools

A custom tool is a tool you define yourself for your specific use case.

Use custom tools when:

  • You want to call your own APIs
  • You want to encapsulate business logic
  • You want the LLM to interact with your database, product, or app
67

Ways to Create Custom Tools

METHOD 01

@tool decorator

Simplest way — just decorate a typed Python function

METHOD 02

StructuredTool + Pydantic

More control over schema with Pydantic models

METHOD 03

BaseTool class

Full control — subclass the abstract base class

# Method 1 — @tool decorator
from langchain.tools import tool

@tool
def multiply(a: int, b: int) -> int:
    """Multiply two numbers"""
    return a * b

result = multiply.invoke({"a": 3, "b": 5})  # → 15
# multiply.name, multiply.description, multiply.args
# Method 2 — StructuredTool + Pydantic
from langchain.tools import StructuredTool
from pydantic import BaseModel, Field

class MultiplyInput(BaseModel):
    a: int = Field(required=True, description="The first number")
    b: int = Field(required=True, description="The second number")

def multiply_func(a: int, b: int) -> int:
    return a * b

multiply_tool = StructuredTool.from_function(
    func=multiply_func,
    name="multiply",
    description="Multiply two numbers",
    args_schema=MultiplyInput
)
# Method 3 — BaseTool class
from langchain.tools import BaseTool
from typing import Type

class MultiplyTool(BaseTool):
    name: str = "multiply"
    description: str = "Multiply two numbers"
    args_schema: Type[BaseModel] = MultiplyInput

    def _run(self, a: int, b: int) -> int:
        return a * b

multiply_tool = MultiplyTool()
result = multiply_tool.invoke({'a': 3, 'b': 3})  # → 9
Note: @tool and StructuredTool are both built on top of BaseTool, which is the abstract base class for all tools in LangChain.

Toolkits

A toolkit is a collection (bundle) of related tools that serve a common purpose — packaged together for convenience and reusability.
GoogleDriveToolKit
GoogleDriveCreateFileToolUpload a file
GoogleDriveSearchToolSearch for a file by name/content
GoogleDriveReadFileToolRead contents of a file
# Creating a custom toolkit
class MathToolkit:
    def get_tools(self):
        return [add, multiply]

toolkit = MathToolkit()
tools = toolkit.get_tools()

for tool in tools:
    print(tool.name, "=>", tool.description)

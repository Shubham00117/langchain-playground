What is a Tool?

A tool is a Python function (or API) packaged in a way the LLM can understand and call when needed.

✓ LLMs are great at

  • Reasoning (Think)
  • Language generation (Speak)

✗ LLMs can't do

  • Access live data (weather, news)
  • Do reliable math
  • Call external APIs
  • Run code
  • Interact with a database

Tools bridge the gap — giving LLMs real-world capabilities.

Pre-built, production-ready tools provided by LangChain. Just import and use — no function logic needed.

# DuckDuckGo Search Example
from langchain_community.tools import DuckDuckGoSearchRun

Custom Tools

A custom tool is a tool you define yourself for your specific use case.

Use custom tools when:

  • You want to call your own APIs
  • You want to encapsulate business logic
  • You want the LLM to interact with your database, product, or app
70

Ways to Create Custom Tools

Method 1 — @tool Decorator

Simplest approach. Add @tool decorator to any function with type hints and a docstring.

PYTHON 
@tool
def multiply(a: int, b: int) -> int:
    """Multiply two numbers"""
    return a * b

result = multiply.invoke({"a": 3, "b": 5})
# Exposes: .name, .description, .args
Method 2 — StructuredTool + Pydantic

Use when you need rich input schema with field descriptions. Define a Pydantic model then pass it to StructuredTool.from_function().

PYTHON 
from langchain.tools import StructuredTool
from pydantic import BaseModel, Field

class MultiplyInput(BaseModel):
    a: int = Field(required=True, description="The first number")
    b: int = Field(required=True, description="The second number")

def multiply_func(a: int, b: int) -> int:
    return a * b

multiply_tool = StructuredTool.from_function(
    func=multiply_func,
    name="multiply",
    description="Multiply two numbers",
    args_schema=MultiplyInput
)
Method 3 — BaseTool Class

BaseTool is the abstract base class for all tools in LangChain. @tool and StructuredTool are both built on top of it. Use for maximum control and customization.

PYTHON 
from langchain.tools import BaseTool
from typing import Type

class MultiplyTool(BaseTool):
    name: str = "multiply"
    description: str = "Multiply two numbers"
    args_schema: Type[BaseModel] = MultiplyInput

    def _run(self, a: int, b: int) -> int:
        return a * b

multiply_tool = MultiplyTool()
result = multiply_tool.invoke({'a': 3, 'b': 3})

Toolkits

A toolkit is a collection (bundle) of related tools that serve a common purpose — packaged for convenience and reusability.

Example: GoogleDriveToolKit

GoogleDriveCreateFileTool Upload a file
GoogleDriveSearchTool Search for a file by name/content
GoogleDriveReadFileTool Read contents of a file

How to use this Toolkit:

PYTHON 
from langchain_community.agent_toolkits import GoogleDriveToolkit

# 1. Initialize the toolkit (requires API client)
toolkit = GoogleDriveToolkit(api_client=client)

# 2. Extract all included tools (Create, Search, Read)
tools = toolkit.get_tools()

# 3. Agent now has access to all Drive capabilities
agent = create_react_agent(llm, tools, prompt)

Creating a Custom Toolkit:

PYTHON 
from langchain_core.tools import tool

# Creating a custom toolkit
class MathToolkit:
    def get_tools(self):
        return [add, multiply] # list of @tool functions

toolkit = MathToolkit()
tools = toolkit.get_tools()

for tool in tools:
    print(tool.name, "=>", tool.description)

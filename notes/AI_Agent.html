What is an AI Agent?

An AI agent is an intelligent system that receives a high-level goal from a user, and autonomously plans, decides, and executes a sequence of actions using external tools, APIs, or knowledge sources — while maintaining context, reasoning over multiple steps, adapting to new information, and optimizing for the intended outcome.
🧠
LLM
Reasoning Brain
+
🔧
TOOLS
APIs · DBs · Search
=
🤖
AGENT
Autonomous System

Key difference from a plain LLM:

🤔 Plain LLM

  • Generates one response
  • No external action
  • Single-step reasoning
  • No memory between calls

🤖 AI Agent

  • Plans multi-step autonomously
  • Calls real tools/APIs
  • Loops until task is done
  • Maintains context across steps

ReAct — Reasoning + Acting

ReAct = Reasoning + Acting. A design pattern for AI agents where the LLM interleaves internal Thought with external Actions (tool use) in a structured, multi-step loop — instead of generating an answer in one go.
💭 Thought
What do I do next?
→
⚡ Action
Call a tool
→
👁 Observation
Tool result
→
✅ Final Answer
Or loop again
↺ This Thought → Action → Observation cycle repeats N times until Final Answer is reached

ReAct is useful for:

Multi-step Problems

Tasks that require multiple queries and decisions

Tool-augmented Tasks

Web search, database lookup, API calls

Transparent Reasoning

Every thought is logged — auditable and debuggable

📄
Original paper: "ReAct: Synergizing Reasoning and Acting in Language Models" — Yao et al., 2022. Princeton University + Google Research Brain Team.

Agent & Agent Executor

🧠 Agent

  • The LLM brain
  • Generates thought traces
  • Decides next action
  • Outputs AgentAction or AgentFinish

🔁 AgentExecutor

  • Orchestrates the entire loop
  • Runs the tool called by agent
  • Feeds result back to agent
  • Loops until Final Answer

AgentExecutor Loop — 5 Steps:

1
Send inputs + previous messages (scratchpad) to the agent
2
Get the next action from agent (AgentAction)
3
Execute that tool with the provided input
4
Add the tool's observation back into the history (scratchpad)
5
Loop again with updated history until agent says Final Answer

ReAct Prompt Template

The ReAct prompt is a StringPromptTemplate pulled from LangChain Hub that instructs the LLM to follow the Thought → Action → Observation format. It provides the exact format the agent must follow.

Pull from LangChain Hub:

from langchain import hub
prompt = hub.pull("hwchase17/react")  # standard ReAct prompt

Prompt structure:

Answer the following questions as best you can. You have access to the following tools: {tools} Use the following format: Question: the input question you must answer Thought: you should always think about what to do Action: the action to take, should be one of [{tool_names}] Action Input: the input to the action Observation: the result of the action ... (this Thought/Action/Action Input/Observation can repeat N times) Thought: I now know the final answer Final Answer: the final answer to the original input question Question: {input} Thought: {agent_scratchpad}
{tools}
{tool_names}
{input}
{agent_scratchpad}

Creating a ReAct Agent — Code

5-step process to build a working ReAct agent in LangChain using DuckDuckGo search as the tool.
S1
Create Tools — import and instantiate DuckDuckGoSearchRun
S2
Pull Prompt — get standard ReAct prompt from LangChain Hub
S3
Create Agent — wire LLM + tools + prompt using create_react_agent
S4
Wrap Executor — wrap agent in AgentExecutor which runs the loop
S5
Invoke — call with user query and get final answer
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
from langchain_community.tools import DuckDuckGoSearchRun
from langchain.agents import create_react_agent, AgentExecutor
from langchain import hub

# Step 1: Tool
search_tool = DuckDuckGoSearchRun()

# Step 2: Prompt
prompt = hub.pull("hwchase17/react")

# Step 3: Agent (LLM + tools + prompt)
llm = ChatOpenAI()
agent = create_react_agent(
    llm=llm,
    tools=[search_tool],
    prompt=prompt
)

# Step 4: Executor (runs the loop)
agent_executor = AgentExecutor(
    agent=agent,
    tools=[search_tool],
    verbose=True
)

# Step 5: Invoke
response = agent_executor.invoke({"input": "3 ways to reach goa from delhi"})
# output → 'The 3 common ways to reach Goa from Delhi are by air, train, and road.'

Creating an Agent Executor

AgentExecutor is the runtime that wraps the agent and manages the full Thought → Action → Observation loop automatically. It handles tool execution and scratchpad updates. 
agent_executor = AgentExecutor(
    agent=agent,       # the ReAct agent (LLM brain)
    tools=[search_tool],  # same tools given to agent
    verbose=True       # prints full thought trace
)

verbose=True shows:

  • Entering AgentExecutor chain
  • Each Thought statement
  • Each Action + Action Input
  • Each Observation result
  • Final Answer

What it manages:

  • Tool execution
  • Scratchpad updates
  • Loop until Final Answer
  • Error handling

Improving the Code — Multi-Tool Agent

Upgrade the agent with a second custom tool — get_weather_data using WeatherStack API. Now the agent can chain two different tools: first search, then weather lookup.

New custom tool:

import requests
from langchain_core.tools import tool

@tool
def get_weather_data(city: str) -> str:
    """This function fetches the current weather data for a given city"""
    url = f'https://api.weatherstack.com/current?access_key=<API_KEY>&query={city}'
    response = requests.get(url)
    return response.json()

Updated full agent with 2 tools:

# Step 1: Both tools
search_tool = DuckDuckGoSearchRun()
# get_weather_data defined above with @tool

# Step 2: Prompt
prompt = hub.pull("hwchase17/react")

# Step 3: Agent — 2 tools now
agent = create_react_agent(
    llm=llm,
    tools=[search_tool, get_weather_data],
    prompt=prompt
)

# Step 4: Executor — same tools list
agent_executor = AgentExecutor(
    agent=agent,
    tools=[search_tool, get_weather_data],
    verbose=True
)

# Step 5: Multi-tool query
response = agent_executor.invoke({
    "input": "Find the capital of Madhya Pradesh, then find its current weather condition"
})

How the agent chains the tools:

THOUGHT 1

"I need to find the capital of Madhya Pradesh first."

ACTION 1

search_tool ← "capital of Madhya Pradesh"

OBSERVATION 1

"Bhopal is the capital of Madhya Pradesh."

THOUGHT 2

"Now I should get the weather in Bhopal."

ACTION 2

get_weather_data ← "Bhopal"

OBSERVATION 2

Weather JSON with temperature, humidity, conditions...

✅ FINAL ANSWER

"Bhopal is the capital of Madhya Pradesh. Current weather: [conditions from API]."

💡
The agent automatically decides which tool to use at each step based on the task — you don't need to specify the order. The ReAct reasoning pattern handles the sequencing.
